# Bundled themes

cAIman is the original application palette. Dracula, Nord, Gruvbox Dark,
Catppuccin Mocha, and Tokyo Night are five established terminal themes selected
for this preview; this is not a measured worldwide popularity ranking.

The 16 ANSI colors, background, foreground, and cursor come from
[Gogh's theme collection](https://github.com/Gogh-Co/Gogh),
[data/themes.json](https://github.com/Gogh-Co/Gogh/blob/master/data/themes.json),
retrieved September 9, 2026. The picker displays TokyoNight as “Tokyo Night”.
Surface, selection, accent and muted UI colors are cAIman adaptations.

Upstream authors:

- Dracula: [Dracula](https://draculatheme.com/)
- Nord: [Arctic Ice Studio](https://www.nordtheme.com/)
- Gruvbox Dark: [morhetz](https://github.com/morhetz/gruvbox)
- Catppuccin Mocha: [Catppuccin](https://github.com/catppuccin)
- Tokyo Night: [folke](https://github.com/folke/tokyonight.nvim)
